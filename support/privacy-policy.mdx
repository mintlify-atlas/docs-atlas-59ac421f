## Overview

BCUninstaller by Marcin Szeniak is committed to protecting your privacy. This policy outlines what information is collected, how it's used, and who has access to it.

<Note>
  All collected information is anonymous and does not include any personally identifiable or sensitive information.
</Note>

## Information We Collect

BCUninstaller collects the following information:

<CardGroup cols={3}>
  <Card title="Usage Statistics" icon="chart-line">
    Anonymous data about how the application is used
  </Card>
  
  <Card title="Error Reports" icon="triangle-exclamation">
    Anonymous crash reports and error information
  </Card>
  
  <Card title="Application Ratings" icon="star">
    User-selected ratings for applications being uninstalled
  </Card>
</CardGroup>

### User ID Generation

During first start of BCUninstaller, a user ID is generated to help keep track of application ratings and usage statistics.

**Important details about the user ID:**
- Can be freely changed by you at any time
- Is not guaranteed to be unique
- Does not contain any personal information
- Used only for aggregating anonymous statistics

<Tip>
  You can modify your user ID in the application settings if desired.
</Tip>

## How We Use Your Information

Marcin Szeniak collects this information to provide the following benefits:

<AccordionGroup>
  <Accordion title="Improve BCUninstaller" icon="code">
    Usage statistics and error reports help identify bugs, performance issues, and areas for improvement. This data guides development priorities and helps make BCU more stable and efficient.
  </Accordion>

  <Accordion title="Provide Overall Application Ratings" icon="star">
    User-selected application ratings are aggregated to generate overall ratings for software. These ratings are visible to all users and help the community make informed decisions about software quality and trustworthiness.
  </Accordion>

  <Accordion title="Help Plan Future Features and Applications" icon="lightbulb">
    Understanding how BCU is used helps guide feature development and plan improvements. Usage patterns inform which features are most valuable and where to focus development efforts.
  </Accordion>
</AccordionGroup>

## Information Sharing

### Who Has Access to Your Data?

Marcin Szeniak shares this information with the following parties:

<Card title="No One" icon="lock">
  Your anonymous usage data and error reports are not shared with any third parties.
</Card>

### Publicly Visible Information

The only information visible to other users is:

**Overall Application Ratings** - User-selected application ratings are aggregated and displayed to all users. Individual ratings are not shown, only the combined overall rating from all BCU users.

<Note>
  When you rate an application, your individual rating is combined with others to create an overall score. Your specific rating is never shown separately.
</Note>
