# Welcome to Bulk Crap Uninstaller

Bulk Crap Uninstaller (BCUninstaller or BCU) is a free and open-source program uninstaller that excels at removing large amounts of applications with minimal user input.

## What is BCU?

BCU is a powerful uninstaller designed to help you efficiently clean up your Windows system. Whether you're an IT professional managing multiple machines or a home user looking to remove unwanted software, BCU provides the tools you need to thoroughly uninstall applications.

<Info>
  BCU is licensed under Apache 2.0 open source license and can be used in both private and commercial settings for free with no obligations.
</Info>

## What Makes BCU Different?

- **Thorough Removal**: Unlike standard uninstallers, BCU can detect and remove leftover files and registry entries
- **Batch Processing**: Run uninstallers according to premade lists for efficient bulk operations
- **Universal Support**: Works with virtually any uninstalling system including Windows Store, Steam, and traditional installers
- **Open Source**: Fully transparent and community-driven development
